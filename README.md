 Terminal Game

A turn-based terminal RPG and dungeon crawler written entirely in Bash script, featuring combat mechanics, character progression, an item shop, random events, and a save and load system.


## ✨ Features
- **Turn-Based Combat:** Quick attacks, high-risk critical strikes, healing potions, and escape mechanics.
- **Leveling & Stats:** Gain XP and Gold to level up and boost Max HP, Attack, and Defense.
- **Dungeon Floors:** Explore randomized events (monsters, treasure chests, healing fountains, traps) and defeat Floor Guardians.
- **Camp Shop & Save System:** Upgrade gear, buy potions, and save/load progress locally (`partida.sav`).
